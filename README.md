# Brown's Automotive — concept website

A single-page concept site for **Brown's Automotive**, an independent auto-repair shop
on E Broadway in Pearland, TX (4.7★, 137 Google reviews). Built as a pitch preview by
Rashad — not the official Brown's Automotive website.

## The idea
The hero is an **interactive instrument cluster**: turn the key, the gauges sweep and the
dashboard warning lights come on, then tap any light to see how Jimmy would diagnose it —
in plain English, with a fair-price / same-day note drawn from the shop's real reviews.
It turns the brand ("the honest hometown mechanic") into something you can touch.

## Build
- Single `index.html`, inline CSS + vanilla JS, no build step or dependencies.
- Two placeholder photos in `images/` (Unsplash) to be swapped for real shots of Jimmy and the shop.
- Fonts: Oswald + Open Sans + Caveat (Google Fonts).
- Marked `noindex, nofollow`; footer labels it a concept preview.
- Appointment form is front-end only — wire up Formspree / Web3Forms before launch.
- `[CONFIRM WITH CLIENT]` tags mark every fact to verify (warranty terms, service area,
  years in business, full service list).

Content is built from public Google / Yelp / Nextdoor reviews, read October 2026.
